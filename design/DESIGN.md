# assembly-api-mcp Design Canon

이 파일은 이 저장소의 canonical 디자인 기준 문서다.

## Purpose

- 공공 데이터 도구답게 신뢰감, 명확성, 접근성을 우선한다.
- 마케팅 페이지나 문서 시각화가 필요해도 과장된 SaaS 스타일보다 정보 전달을 우선한다.
- 데이터 밀도가 높아도 읽기 쉬운 계층 구조를 유지한다.

## Visual direction

- Tone: civic, trustworthy, calm, precise
- Color: 저채도 블루/슬레이트 계열 중심, 경고/강조 색은 제한적으로 사용
- Typography: 제목은 단단하고 명료하게, 본문은 긴 설명을 버티는 가독성 우선
- Layout: 카드 남발보다 문서형 섹션과 표 기반 구조를 선호
- Motion: 필요 최소한, 상태 변화나 피드백에만 사용

## Do

- API, 입법, 의정활동 데이터를 비교/추적하기 쉬운 레이아웃을 쓴다.
- 모바일에서도 표와 긴 텍스트를 무리 없이 읽을 수 있게 설계한다.
- 그래프나 수치가 들어가면 출처와 기준 시점을 분명히 드러낸다.

## Don't

- 네온, 과한 글로우, 과장된 3D 효과를 기본 스타일로 쓰지 않는다.
- 장식성 때문에 정보 위계를 흐리지 않는다.
- 공공성 있는 데이터에 게임 UI 같은 톤을 섞지 않는다.

## Source policy

- 외부 디자인 초안은 `design/inspirations/`에 저장한다.
- TypeUI 등 생성물은 `design/skills/`에 저장한다.
- 이 파일만 최종 기준으로 유지한다.
